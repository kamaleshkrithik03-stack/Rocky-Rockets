# 🚀 Rocky Rockets

A terminal-based rocket simulator exploring variable-mass differential motion, TWR constraints, and suborbital flight physics.

Built for the Hack Club Terra challenge.

## Features
- Variable mass depletion via Newton's Second Law
- Launchpad clamping logic (TWR > 1.0)
- Telemetry readouts for altitude, velocity, and propellant state

## How to Run
```bash
python "Rocky rockeets.py"
